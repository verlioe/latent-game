# LATENT — 潛空間防禦

單檔 HTML 的倖存者型競技場射擊（Vampire Survivors 風格）。零依賴、零外部資源，
音效與 BGM 都是 WebAudio 即時合成。雙擊 `index.html` 就能玩。

## 操作

| 按鍵 | 動作 |
| --- | --- |
| `W A S D` / 方向鍵 | 移動 |
| — | 自動瞄準最近敵人並射擊 |
| `Space` | 衝刺（無敵幀，冷卻 1.35 秒起） |
| `1` `2` `3` | 升級時選卡 |
| `Esc` | 暫停（顯示 DPS／傷害／當前武器） |
| `F2` | 除錯資訊 |
| 手把 | 左搖桿移動、A 鍵衝刺 |

## 在手機上玩（同一個 Wi-Fi）

雙擊 `start-server.cmd`，手機連同一個 Wi-Fi 後掃 `qr.png` 或開 `http://<電腦區網IP>:8000/`。

- 觸控：按住畫面任一處拖曳＝浮動搖桿，右下圓鈕＝衝刺，升級卡片直接點。
- 停止伺服器：`Get-NetTCPConnection -LocalPort 8000 -State Listen | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }`

## 一局怎麼玩

**15 分鐘制**：撐到 14:00 會出現**最終核心**，擊敗它即通關（結算核心 ×1.5）。
途中每 60 秒一隻首領、每 30 秒一群包圍波、不定時精英怪。

## 世界

- 地圖 **2800 × 2100**，鏡頭跟著你，左下角有小地圖（顯示視窗範圍、固定寶箱、首領）。
- **可破壞物件**：撞不到但打得破，掉落經驗、24% 機率噴寶箱。
- **固定寶箱**：世界四個角落各一個，一次給 3 個升級。

## 武器

主砲自動瞄準；副武器由升級卡取得，各 5 級：

| 武器 | 行為 |
| --- | --- |
| 環繞刃 | 貼身旋轉，每 0.38 秒可再切同一隻 |
| 追蹤飛彈 | 自動追尾、命中小爆炸 |
| 地刺 | 敵人腳下延遲 0.42 秒引爆 |
| 裂空鞭 | 正面扇形近距離重擊＋擊退 |
| 迴力鏢 | 擲出後折返，來回都傷害 |
| 貫穿光束 | 朝瞄準方向持續貫穿 |

**進化只能由寶箱觸發**：條件達成後，下一個寶箱（含精英/首領掉的）會直接給進化，不再出現在升級卡裡。

| 進化 | 條件 |
| --- | --- |
| 軌道鋸 | 環繞刃 Lv5 ＋ 起手節奏 ≥3 |
| 蜂群飛彈 | 飛彈 Lv5 ＋ 多頭注意力 ≥3 |
| 裂地脈衝 | 地刺 Lv5 ＋ 權重增強 ≥3 |
| 斷界鞭 | 裂空鞭 Lv5 ＋ 起步加速 ≥3 |
| 雙旋刃 | 迴力鏢 Lv5 ＋ 尖峰激活 ≥3 |
| 湮滅射線 | 光束 Lv5 ＋ 權重增強 ≥5 |

## 欄位與稀有度

- **武器 6 格、被動 6 格**（角色起始武器會佔用武器格）。滿了就只會出現「升級」卡，不會再給新東西。
- 每張卡有**出現權重**：核心被動 100、一般被動 60～92、武器 50～72；升級選項是加權抽 3 張，不是等機率。
- 卡片右下角會標「新武器／新被動」或目前等級；升級畫面標題會顯示 `武器 x/6　被動 y/6`。

| 關卡 | 世界 | 特色 | 核心 |
| --- | --- | --- | --- |
| 開闊平原 | 2800×2100 | 標準 | ×1 |

## 模式

在「永久強化 → 設定 → 模式」切換，效果直接反映在結算：

| 模式 | 效果 |
| --- | --- |
| Hurry | 遊戲時鐘 ×2（波次更快來）、經驗 +25% |
| Inverse | 敵人生命 ×3、移速 +15%，核心結算 ×2 |
| Endless | 不生成最終核心，時間無上限 |

| Union | 條件 |
| --- | --- |

## 敵人

雜訊（基礎）、臭蟲（蛇行）、幻覺（死亡分裂）、過擬合（坦克）、
**砲塔**（保持距離發射彈幕）、**爆炸怪**（死亡炸傷附近）、
**衝鋒怪**（預告後直線衝刺）、**推進牆**（高血量慢速推進）、
**精英**（金環、3.2 倍血、掉寶箱）、**首領**（每 60 秒）、**最終核心**（14:00）。

首領有三種模式輪替（依擊殺數 `% 3`）：**召喚型**（叫小怪）、**衝鋒型**（預告後直線衝撞）、**彈幕型**（環形彈幕）；最終核心同時具備召喚＋彈幕。

## 掉落物

寶箱（擊殺 2.2%、精英／首領必掉）給 1–3 個免費升級；治療包 +30 HP、全場磁鐵、炸彈清場。

## Combo

2.5 秒內連續擊殺累積倍率（最高 ×3），擊殺音隨連段變尖。

## 場外成長

結算核心：`擊殺×0.3 ＋ 存活秒數×0.3 ＋ 等級×2`（上限 400；通關 ×1.5）。

- **角色**：核心（均衡）／銳爪（傷害＋25%、生命−25、起手環繞刃 Lv2）／壁壘（生命＋60、移速−10%、起手地刺 Lv2）
- **永久強化**：生命／傷害／射速／移速／拾取／經驗 各 5 級
- **開局自選**（−40 核心）、**核心復活**（30＋等級×5，每局限一次）
- **成就** 11 個（含通關）、**排行榜** 前 5 名、**武器圖鑑**
- **設定**：傷害數字、畫面震動、音樂開關（存 `latent.settings`）

## 想調整

- 世界大小：`G.world`
- 生成節奏：`spawnLogic()`；包圍波：`surroundWave()`
- 首領：`BOSS_INTERVAL`、`spawnBoss()`、`spawnFinalBoss()`、`FINAL_AT`
- 武器數值：`updateWeapons()`；進化條件：`EVOLUTIONS`
- 核心結算：`endGame()` 內的 `base`

## 實作備註

- 60Hz 固定步進，渲染跟 `requestAnimationFrame`；首領死亡慢動作（`G.slow`，更新 ×0.35）
- 相機位移整數化後 translate，實體以 `inView()` 剔除
- 光暈用預先烘焙的 radial-gradient sprite；螢幕疊加（環境光＋暗角）在 resize 時烘焙
- BGM 用 lookahead 排程（`setInterval` 120ms，音訊時鐘對齊），強度隨存活時間升調

## 成就解鎖與收集

- 13 個成就，其中「銳爪解鎖」（單場 200 擊殺）與「壁壘解鎖」（存活 6 分鐘）會直接**解鎖角色**。
- 永久強化面板底部顯示收藏完成度（角色 x/3、成就 y/13）。
- **密技**：標題畫面依序輸入 `latent` → +150 核心（每存檔一次）。

## AI 隊友

每局都有一台跟著你、自動射擊最近敵人的小型無人機（55% 傷害），會出現在角色左後方。

## 節奏與祭壇（研究後調整）

- **首領固定 120 秒**、事件固定順序（3:00 寶箱雨 → 6:00 精英潮 → 9:00 包圍潮 → 12:00 精英潮），讓玩家可以倒數準備。
- **升級可跳過**：三選一之外的第四個選項，保留這次升級並回復 6% 生命。
- **敗因診斷**：死亡頁列出「本局缺」——武器欄位、被動欄位、沒進化、沒踩祭壇、沒第二張 Arcana。
- **里程碑祭壇**：每 4 分鐘在附近 520px 生成一座（不再隨機散佈），踩下去敵血 +25%、核心 +50%。

## 補給空投與資料碎片（局內經濟）

- **資料碎片**：擊殺 +1（精英 +5、首領 +20），顯示在暫停面板。
- **補給空投**：每 3 分鐘在附近 260px 投放一個補給箱，打開後三選一：
  | 選項 | 效果 | 花費 |
  | --- | --- | --- |
  | 緊急修復 | 回復 30% 生命 | 免費 |
  | 擴充槽位 | 本局武器欄位 +1 | 5 碎片 |
  | 被動槽位 | 本局被動欄位 +1 | 5 碎片 |
  | 免費升級 | 獲得 1 個隨機升級 | 3 碎片 |
  碎片不足時該卡片會變灰、不能選。

## 手動瞄準與裝備掉落

- **手動瞄準**（設定可切換）：滑鼠位置或手把右搖桿決定射擊方向；預設關閉，維持自動瞄準。
- **裝備掉落**：精英與首領死亡時掉落裝備，四種詞條（火力核心 +傷害／超頻線圈 +射速／推進模組 +移速／瞄準晶片 +暴擊），首領掉的數值 ×1.6。
- 走近自動拾取，**數值比身上高才替換**（較低會直接消耗掉），替換時會浮出「裝備：名稱 +X%」。

## 裝備背包（3 格）與 Boss 名稱

- 裝備改為 **3 格背包**：滿了之後，新裝備只有在數值高於最弱那件時才會替換，否則直接丟棄。
- 四種詞條各自加成：火力核心（傷害）、超頻線圈（射速）、推進模組（移速）、瞄準晶片（暴擊）。
- **Boss 有名字了**：孵化者（召喚）、裂解者（衝撞）、迴響（彈幕）、最終核心，血條會顯示對應名稱。

遊戲中按 B 隨時開店，用資料碎片購買（或按「離開」不買）：

| 商品 | 花費 |
| --- | --- |
| 緊急修復（回復 30% 生命） | 免費 |
| 免費升級（隨機 1 個） | 3 碎片 |
| 擴充槽位（武器欄位 +1） | 5 碎片 |
| 被動槽位（被動欄位 +1） | 5 碎片 |

碎片不足的卡片會變灰、不能點。商店與 3 分鐘空投共用同一組商品，差別是空投是「免費三選一」、商店是「花碎片買」。

## 傳奇裝備與波數

- **傳奇裝備**：首領 30% 機率掉落粉紅色的 ★ 裝備，效果是行為改變而非數值：
  - ★ 裂變核心：擊殺時產生小爆炸（半徑 110、傷害 35）
  - ★ 嗜血協議：每次擊殺回復 1.5% 最大生命
- **波數**：每分鐘一波，死亡頁顯示「第 N 波」，並把最高波數寫入 latent.bestWave。
- **Boss 預告**：出現前 3 秒全畫面警示「⚠ 名稱 即將出現 + 倒數」，登場時震動與音效。

### 勝利流程修復（第十階段）

擊敗最終核心時，ictory() 現在會：先嘗試完整結算，任何例外都會被捕捉（不再讓畫面卡住），最後**無條件顯示勝利結算畫面**並把 mode 設為 dead、won = true。

實測：呼叫 ictory() → mode = dead、won = true、結算面板可見、動畫持續跑、零 JS 例外。

### 效能優化（第十一階段）

- 距離玩家超過 **1500px** 的敵人**跳過 AI 運算**（不追蹤、不開火、不移動）
- 粒子上限 260 → **200**
- 星空密度：桌面 3 → **2** 顆／格（觸控版 1 顆）
- 既有的實體上限：數字 90／環 50／子彈 260／敵彈 160／碎片 300

壓力測試（300 隻敵人、t=400）：無 JS 例外；headless 軟體渲染下約 33 FPS（實機有 GPU 會更高）。
